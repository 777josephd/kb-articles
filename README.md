# IT Knowledge Base — End User Documentation

This repository contains a collection of plain-English IT support articles written for non-technical end users. Each article addresses a common help desk issue and is structured to help users self-resolve where possible, gather the right information before calling in, and understand when escalation is necessary.

## Purpose

Effective help desk support is about reducing contacts, setting user expectations, and communicating technical concepts clearly to non-technical audiences.

These articles are written to reflect real support scenarios, structured around the triage logic a support analyst would apply: starting with most common causes, eliminating variables in order, and escalating only when self-service options are exhausted.

Each article follows a consistent structure:
- Audience and scope stated at the top
- Plain-English explanations of technical concepts - no assumed IT knowledge
- Ordered troubleshooting steps from most common cause to least common cause
- Clear escalation criteria so users know when to stop self-troubleshooting
- Structured intake information to reduce handle time when users do contact support

Articles intentionally avoid jargon where plain language is equally adequate. Where technical terms are necessary, they are defined in context.
